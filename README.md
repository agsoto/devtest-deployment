# Development & Testing Sandbox 🧪🚧

This repository is intentionally used as a personal **development and testing environment**.  
It acts like a **lightweight proxy** for deploying to a **GitHub Pages subpath**, so real projects don’t get obliterated by whatever chaos you're testing today.

## Purpose 🎯

- Prototype ideas before tossing them into actual projects  
- Test how GitHub Pages behaves with routing and subpath deployments  
- Experiment with layouts, components, configs, and whatever else you feel like breaking  
- Validate workflows, automation, CI setups, and general tinkering in a safe space  

## Important Notice ⚠️

This isn’t meant to be a public masterpiece, but hey, free GitHub Pages is free GitHub Pages.  
**Assume everything here is for testing purposes only.**

If something looks half-baked, unstable, or deeply experimental… that’s because it is.  
This whole repo is basically a **sandbox for trying stuff out**, nothing more.

## Notes 📓

If you somehow wandered in here:  
thanks for the curiosity, but don’t expect anything polished, valuable, or even remotely stable.  
This repo exists so real projects can keep their dignity.
